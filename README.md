# ☕ Core Java Programs

Welcome to the **Core Java Programs** repository! 🚀

This repository contains a collection of **Core Java programs** covering Java fundamentals, OOP concepts, arrays, strings, collections, exception handling, file handling, multithreading, and other important concepts.

It is useful for **BCA/BSc/BE students, beginners, interview preparation, lab practice, and anyone learning Java**.

# 🛠️ Requirements

Before running these programs, install:

* **Java JDK 8 or above**
* Any Java IDE or code editor

Recommended:

* IntelliJ IDEA
* Eclipse
* VS Code
* NetBeans

Check Java installation:

```bash
java -version
```

Check Java compiler:

```bash
javac -version
```

---

# ▶️ How to Run

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project:

```bash
cd Core-Java-Programs
```

Compile a Java program:

```bash
javac HelloWorld.java
```

Run the program:

```bash
java HelloWorld
```
